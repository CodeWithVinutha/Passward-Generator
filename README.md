# Password Generator

A simple web-based password generator built with HTML, CSS, and JavaScript.

## Features
- Choose password length (1-30 characters)
- Optionally include lowercase, uppercase, numbers, and symbols
- Copy generated password to clipboard

## Usage
1. Open `index.html` in your browser.
2. Select your desired options and click 'Generate password'.
3. Click the copy icon to copy the password to your clipboard.
